$db — har bir foydalanuvchining o'z brauzeridagi baza. U offline ilovalar, qoralamalar, sozlamalar, kesh va prototiplar uchun. Foydalanuvchilar o'rtasida umumiy ma'lumot uchun server kerak (Comet Server — roadmap'da, xuddi shu sintaksis bilan).

$db — база в браузере каждого пользователя. Для офлайн-приложений, черновиков, настроек, кэша и прототипов. Для общих данных нужен сервер (Comet Server в roadmap — с тем же синтаксисом).

$db lives in each user's own browser. Use it for offline apps, drafts, settings, caches and prototypes. Data shared between users needs a server (Comet Server is on the roadmap, with the same syntax).
