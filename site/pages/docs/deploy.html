Comet sayti — oddiy statik fayllar. Istalgan hostingga yuklang. Faqat bitta sozlama kerak: noma'lum manzillar index.html'ni qaytarishi. Сайт на Comet — обычные статические файлы. Загружайте на любой хостинг. Нужна одна настройка: неизвестные адреса должны отдавать index.html. A Comet site is just static files. Upload them anywhere. You need one setting: unknown paths must serve index.html.

Nega? Foydalanuvchi /docs/routing'ni to'g'ridan-to'g'ri ochsa, server bunday faylni topmaydi. U index.html'ni qaytarsa, Comet router kerakli sahifani o'zi yuklaydi.

Почему? Если пользователь откроет /docs/routing напрямую, сервер не найдёт такой файл. Если он вернёт index.html, роутер Comet сам загрузит нужную страницу.

Why? When someone opens /docs/routing directly, the server has no such file. If it returns index.html instead, the Comet router loads the right page itself.

GitHub Pages

GitHub Pages noma'lum manzilda 404.html'ni ko'rsatadi. Shunchaki index.html'ni 404.html nomi bilan nusxalang. Sayt username.github.io/repo/ ichida bo'lsa, <base href="/repo/"> qo'shing va havolalarni nisbiy yozing (href="docs", /docs emas). Ushbu sayt GitHub Pages'da aynan shunday ishlaydi.

GitHub Pages на неизвестный адрес отдаёт 404.html. Просто скопируйте index.html в 404.html. Если сайт лежит в username.github.io/repo/, добавьте <base href="/repo/"> и пишите относительные ссылки (href="docs", а не /docs). Этот сайт так и работает на GitHub Pages.

GitHub Pages serves 404.html for unknown paths. Just copy index.html to 404.html. If the site lives at username.github.io/repo/, add <base href="/repo/"> and use relative links (href="docs", not /docs). This very site runs on GitHub Pages that way.
