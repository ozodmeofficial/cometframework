Моки подключаются на уровне window.fetch: их видят c-get, $fetch, обычный fetch() и даже сторонние библиотеки. Остальные запросы идут в сеть.

Mocks hook in at the window.fetch level: c-get, $fetch, plain fetch() and even third-party libraries see them. Unmatched requests go to the real network.
