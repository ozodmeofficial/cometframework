Comet'da holat — oddiy JavaScript obyekt. Uni o'zgartirasiz, UI o'zi yangilanadi. Состояние в Comet — обычный JavaScript-объект. Меняете его — UI обновляется сам. State in Comet is a plain JavaScript object. Change it, and the UI updates itself.

c-data

c-data reaktiv qamrov (scope) yaratadi. Ichki elementlar unga murojaat qila oladi. Getterlar computed qiymat bo'ladi, metodlar ichida this holatga ishora qiladi.

c-data создаёт реактивную область (scope). Вложенные элементы видят её данные. Геттеры работают как computed, в методах this указывает на состояние.

c-data creates a reactive scope that nested elements can read. Getters act as computed values; inside methods, this is the state.

Ichma-ich qamrovlarВложенные областиNested scopes

Ichki c-data tashqi qamrovdagi o'zgaruvchilarni ko'radi va ularga yoza oladi.

Вложенный c-data видит переменные внешней области и может их изменять.

An inner c-data can read — and write — variables of outer scopes.

c-persist

c-persist qo'shilgan c-data localStorage bilan avtomatik sinxronlanadi, hatto tablar orasida ham. c-persist.session — sessionStorage.

c-data с c-persist автоматически синхронизируется с localStorage, даже между вкладками. c-persist.session — sessionStorage.

A c-data with c-persist auto-syncs to localStorage — even across tabs. c-persist.session uses sessionStorage.

⚙

Ichki ishlash: Proxy asosidagi nozik reaktivlik. Har bir effekt qaysi xususiyatni o'qiganini eslab qoladi va faqat o'sha o'zgarganda qayta ishlaydi. O'zgarishlar mikrotaskda guruhlanadi, shuning uchun 100 ta o'zgarish = 1 ta DOM yangilanishi.

Под капотом: точечная реактивность на Proxy. Каждый эффект запоминает прочитанные свойства и перезапускается только при их изменении. Изменения группируются в микрозадаче: 100 изменений = 1 обновление DOM.

Under the hood: Proxy-based fine-grained reactivity. Each effect remembers exactly which properties it read and re-runs only when those change. Updates are batched in a microtask, so 100 changes = 1 DOM update.
