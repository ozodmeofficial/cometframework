c-text · c-html

c-text elementning butun matnini almashtiradi. c-html HTML'ni qo'yadi — faqat ishonchli ma'lumot uchun ishlating (XSS xavfi).

c-text заменяет весь текст элемента. c-html вставляет HTML — используйте только для доверенных данных (риск XSS).

c-text replaces the element's text. c-html inserts HTML — only use it with trusted content (XSS risk).

Ro'yxatlarСпискиLists

c-for massiv, obyekt yoki son bo'yicha aylanadi. c-key berilsa, elementlar kalit bo'yicha qayta ishlatiladi va joyi o'zgartiriladi — bu tartiblash va o'chirishda tez hamda input holatini saqlaydi.

c-for перебирает массив, объект или число. С c-key элементы переиспользуются и перемещаются по ключу — это быстро при сортировке и удалении и сохраняет состояние input.

c-for loops over arrays, objects or numbers. With c-key, rows are reused and moved by key — fast for sorting/removal and it preserves input state.

Atributlarni bog'lashПривязка атрибутовAttribute binding

:atribut="ifoda" (yoki c-bind:atribut). false/null atributni olib tashlaydi. :class va :style obyekt va massivlarni qabul qiladi va mavjud klasslarni buzmaydi — Tailwind bilan ideal.

:атрибут="выражение" (или c-bind:атрибут). false/null убирает атрибут. :class и :style принимают объекты и массивы и не ломают существующие классы — идеально для Tailwind.

:attr="expression" (or c-bind:attr). false/null removes the attribute. :class and :style accept objects and arrays and never clobber existing classes — perfect with Tailwind.
