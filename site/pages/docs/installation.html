O'rnatishУстановкаInstallation

Comet'ni o'rnatish — bu bitta qator. npm, Node.js yoki terminal shart emas. Установка Comet — это одна строка. npm, Node.js и терминал не нужны. Installing Comet is one line. No npm, no Node.js, no terminal required.

Добавьте скрипт в <head> без defer. Он небольшой и применяет тёмную тему и c-cloak до отрисовки (без мерцания).

Put the script in <head>, without defer. It is small and applies dark mode and c-cloak before the first paint (no flash).

Pin a version in production (@v0.1.0). @main always serves the latest code and jsDelivr may cache it for a few hours.
