Reaktiv URLРеактивные URLReactive URLs

URL ichidagi {{ }} o'zgarsa, so'rov qayta yuboriladi. Qiymatlar avtomatik encodeURIComponent qilinadi. Eskirgan javoblar e'tiborsiz qoldiriladi — "race condition" bo'lmaydi.

Если меняется {{ }} в URL — запрос повторяется. Значения кодируются через encodeURIComponent. Устаревшие ответы игнорируются — гонок нет.

When a {{ }} inside the URL changes, the request re-runs. Values are encodeURIComponent-encoded. Stale responses are discarded — no race conditions.

Smart sync

Muvaffaqiyatli POST /api/todos, PATCH /api/todos/5 yoki DELETE /api/todos/5'dan keyin sahifadagi c-get="/api/todos…" elementlari o'zi qayta yuklanadi. Qo'lda yangilash kodi kerak emas. Mutatsiyadan keyin GET keshi ham tozalanadi.

После успешного POST /api/todos, PATCH /api/todos/5 или DELETE /api/todos/5 элементы c-get="/api/todos…" перезагружаются сами. Никакого ручного обновления. Кэш GET тоже очищается.

After a successful POST /api/todos, PATCH /api/todos/5 or DELETE /api/todos/5, every c-get="/api/todos…" on the page refreshes itself. No manual refresh code. The GET cache is cleared too.

HTML almashtirishЗамена HTMLHTML swaps

Server HTML qaytarsa, u element ichiga (yoki c-target'ga) qo'yiladi va ichidagi Comet direktivalari ishga tushadi. c-swap: inner (standart), outer, append, prepend, before, after.

Если сервер вернул HTML, он вставляется в элемент (или в c-target), а директивы Comet внутри оживают. c-swap: inner (по умолчанию), outer, append, prepend, before, after.

If the server returns HTML, it's swapped into the element (or c-target) and any Comet directives inside come alive. c-swap: inner (default), outer, append, prepend, before, after.
