Tezlik haqida haqiqatПравда о скоростиThe truth about speed

"X freymworkdan 20 barobar tez" degan da'volarga ishonmang. Barcha freymworklar oxir-oqibat bir xil brauzer DOM API'sini chaqiradi va bu chegarani hech kim yengib o'tolmaydi. Svelte, Solid va vanilla JS deyarli bir xil tezlikda; React virtual DOM tufayli ko'p operatsiyalarda ulardan sekinroq, lekin bir necha barobar emas.

Не верьте заявлениям «в 20 раз быстрее фреймворка X». Все фреймворки в итоге вызывают один и тот же DOM API браузера, и этот предел никто не обходит. Svelte, Solid и vanilla JS почти равны; React из-за virtual DOM медленнее во многих операциях, но не в разы.

Don't trust "20× faster than framework X" claims. Every framework ends up calling the same browser DOM APIs, and nobody gets past that ceiling. Svelte, Solid and vanilla JS are close to equal; React is slower in many operations because of its virtual DOM — but not by multiples.

Comet virtual DOM ishlatmaydi: har bir {{ }} yoki direktiva o'z effektiga ega va faqat o'zi o'qigan qiymat o'zgarganda ishlaydi. c-for kalit bo'yicha DOM tugunlarini qayta ishlatadi. Yangilanishlar mikrotaskda guruhlanadi. Bu Solid/Vue reaktivligiga o'xshash yondashuv.

Comet не использует virtual DOM: у каждого {{ }} и директивы свой эффект, который перезапускается только при изменении прочитанных им значений. c-for переиспользует узлы по ключу. Обновления группируются в микрозадаче. Подход похож на реактивность Solid/Vue.

Comet has no virtual DOM: each {{ }} and directive owns an effect that only re-runs when the values it read change. c-for reuses nodes by key. Updates are batched in a microtask. It's the same family of approach as Solid's and Vue's reactivity.

Comet ifodalarni brauzerda new Function bilan kompilyatsiya qiladi (kesh bilan). Bu build'siz ishlashning narxi: juda katta ro'yxatlarda Comet kompilyatsiya qilinadigan freymworklardan (Svelte, Solid) biroz sekinroq bo'lishi mumkin. Bosh sahifadagi benchmark brauzeringizda Comet'ni qo'lda yozilgan vanilla kod bilan solishtiradi.

Comet компилирует выражения в браузере через new Function (с кэшем). Это цена работы без сборки: на очень больших списках Comet может немного уступать компилируемым фреймворкам (Svelte, Solid). Бенчмарк на главной сравнивает Comet с ручным vanilla-кодом прямо в вашем браузере.

Comet compiles expressions in the browser with new Function (cached). That's the price of no build step: on very large lists Comet can be a bit slower than compiled frameworks (Svelte, Solid). The benchmark on the home page compares Comet with hand-written vanilla code right in your browser.
