O'z hodisalaringiz: $emitСвои события: $emitCustom events: $emit

$emit(nom, ma'lumot) elementdan yuqoriga ko'tariluvchi (bubbling) hodisa yuboradi. Ota element uni @nom bilan ushlaydi, ma'lumot — $event.detail.

$emit(имя, данные) отправляет всплывающее событие от элемента. Родитель ловит его через @имя, данные — в $event.detail.

$emit(name, detail) dispatches a bubbling event from the element. A parent catches it with @name; data is in $event.detail.

Hodisa nomlarida kebab-case ishlating: HTML atribut nomlari kichik harflarga aylantiriladi.

Используйте kebab-case в именах событий: HTML приводит имена атрибутов к нижнему регистру.

Use kebab-case event names: HTML lowercases attribute names.

c-hotkey

Global klaviatura yorliqlari. mod — Mac'da ⌘, Windows/Linux'da Ctrl. Element input bo'lsa — fokus oladi, aks holda — bosiladi.

Глобальные горячие клавиши. mod — ⌘ на Mac, Ctrl на Windows/Linux. Если элемент — поле ввода, он получает фокус, иначе — нажимается.

Global keyboard shortcuts. mod is ⌘ on Mac and Ctrl elsewhere. Inputs get focused; anything else is clicked.
