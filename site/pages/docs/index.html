Comet nima?Что такое Comet?What is Comet?

Comet — build talab qilmaydigan web freymwork. U bitta <script> tegi orqali ulanadi va oddiy HTML'ni reaktiv, ko'p sahifali SPA ilovaga aylantiradi. Comet — веб-фреймворк, которому не нужна сборка. Он подключается одним тегом <script> и превращает обычный HTML в реактивное многостраничное SPA. Comet is a web framework that needs no build step. It is added with a single <script> tag and turns plain HTML into a reactive, multi-page SPA.

Nega Comet?Зачем Comet?Why Comet?

Zamonaviy frontend ko'pincha "Hello world" uchun ham yuzlab paket, bundler, konfiguratsiya va build bosqichini talab qiladi. Comet boshqacha yo'l tutadi: brauzer allaqachon juda kuchli, shuning uchun freymworkning vazifasi — HTML'ga yetishmayotgan narsalarni qo'shish, xolos.

Современный фронтенд часто требует сотни пакетов, бандлер, конфиги и шаг сборки даже для «Hello world». Comet идёт другим путём: браузер уже очень мощный, и задача фреймворка — лишь добавить то, чего не хватает HTML.

Modern frontend often needs hundreds of packages, a bundler, config files and a build step — even for "Hello world". Comet takes another path: the browser is already powerful, so the framework's job is only to add what HTML is missing.

Qachon ishlatish kerakКогда использоватьWhen to use it

Comet quyidagilar uchun juda mos: landing sahifalar, admin panellar, MVP va prototiplar, ichki korporativ tizimlar, mavjud backend (Laravel, Django, Express…) ustidagi interfeyslar, kichik va o'rta SPA'lar.

Comet отлично подходит для: лендингов, админок, MVP и прототипов, внутренних корпоративных систем, интерфейсов поверх существующего бэкенда (Laravel, Django, Express…), небольших и средних SPA.

Comet is a great fit for landing pages, admin panels, MVPs and prototypes, internal tools, UIs on top of an existing backend (Laravel, Django, Express…), and small-to-medium SPAs.

⚠

Halol cheklov: v0.1 server tomonda render (SSR) qilmaydi. Agar sahifa qidiruv tizimlarida birinchi o'rinda bo'lishi juda muhim bo'lsa, hozircha Next.js/Nuxt/Astro'ni tanlang yoki muhim kontentni index.html'ga statik yozing. Prerender (SSG) — v0.2 rejasida.

Честное ограничение: в v0.1 нет серверного рендеринга (SSR). Если SEO критично, пока выбирайте Next.js/Nuxt/Astro или пишите важный контент статически в index.html. Пререндер (SSG) запланирован в v0.2.

Honest limitation: v0.1 has no server-side rendering. If SEO is critical, pick Next.js/Nuxt/Astro for now, or write key content statically in index.html. Prerendering (SSG) is planned for v0.2.
