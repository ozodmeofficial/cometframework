Til tartibi: saqlangan tanlov → brauzer tili → default. Tanlov localStorage'da eslab qolinadi, <html lang> avtomatik yangilanadi. Tarjimalar sahifa chizilishidan oldin yuklanadi — kalitlar ko'rinib qolmaydi.

Порядок выбора языка: сохранённый → язык браузера → default. Выбор запоминается в localStorage, <html lang> обновляется. Переводы загружаются до отрисовки — ключи не мелькают.

Language order: saved choice → browser language → default. The choice is remembered in localStorage and <html lang> is updated. Translations load before the first render — keys never flash.

Butun bloklarni tarjima qilish: c-langПеревод целых блоков: c-langTranslating whole blocks: c-lang

Uzun matnlar uchun JSON kalitlari noqulay. c-lang bilan har bir tildagi variantni to'g'ridan-to'g'ri HTML'da yozing — faqat joriy til ko'rinadi. Bu CSS orqali ishlaydi, shuning uchun miltillash yo'q. Ushbu hujjatlar aynan shunday yozilgan.

Для длинных текстов ключи JSON неудобны. С c-lang пишите варианты на каждом языке прямо в HTML — виден только текущий. Работает через CSS, без мерцания. Эта документация написана именно так.

JSON keys are awkward for long text. With c-lang you write each language's version right in the HTML and only the current one is shown. It's CSS-driven, so there's no flicker. These docs are written exactly this way.
