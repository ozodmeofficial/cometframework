Sahifa fayllari — oddiy HTML qismlar. Ularga script ulash shart emas. Sahifadagi <title> va <meta name="description"> avtomatik qo'llanadi, <script>'lar bajariladi.

Файлы страниц — обычные фрагменты HTML, подключать скрипт не нужно. <title> и <meta name="description"> применяются автоматически, <script> выполняются.

Page files are plain HTML fragments — no script tag needed. Their <title> and <meta name="description"> are applied automatically, and <script> tags run.

To'liq HTML hujjatlar (<html>…</html>) ham ishlaydi — Comet ulardan <body> (yoki [c-view]) ichini oladi. Ya'ni mavjud ko'p sahifali saytni ham SPA'ga aylantirish mumkin.

Полные HTML-документы (<html>…</html>) тоже работают — Comet берёт содержимое <body> (или [c-view]). Так можно превратить в SPA и существующий многостраничный сайт.

Full HTML documents (<html>…</html>) work too — Comet takes the contents of <body> (or [c-view]). So an existing multi-page site can become an SPA.

HavolalarСсылкиLinks

Oddiy <a href> ishlating — Comet ichki havolalarni o'zi ushlaydi. Tashqi havolalar, target="_blank", download, fayllar (.pdf, .zip) va c-reload qo'yilganlar odatdagidek ochiladi.

Используйте обычные <a href> — Comet сам перехватывает внутренние ссылки. Внешние, target="_blank", download, файлы (.pdf, .zip) и ссылки с c-reload открываются как обычно.

Use plain <a href> — Comet intercepts internal links. External links, target="_blank", download, files (.pdf, .zip) and links with c-reload behave normally.

Prefetch: при наведении (или касании на телефоне) страница загружается заранее, поэтому клик открывает её почти мгновенно. Отключить: Comet.config({ prefetch: false }).

Prefetch: pages load on hover (or touch start on phones), so clicks feel instant. Disable with Comet.config({ prefetch: false }).

LayoutlarЛейаутыLayouts

Sahifa c-layout="docs" belgisini qo'ysa, layouts/docs.html yuklanadi va sahifa uning c-outlet elementiga joylanadi. Bir xil layoutli sahifalar orasida o'tganda layout (masalan, sidebar va uning skroll holati) qayta chizilmaydi. Bu docs sayti aynan shunday qurilgan.

Если страница помечена c-layout="docs", загружается layouts/docs.html, а страница вставляется в его c-outlet. При переходе между страницами одного лейаута он (сайдбар и его прокрутка) не перерисовывается. Эта документация устроена именно так.

When a page is marked c-layout="docs", layouts/docs.html is loaded and the page renders into its c-outlet. Navigating between pages with the same layout does not re-render it (the sidebar keeps its scroll). These docs are built exactly like that.

O'tish animatsiyalariАнимации переходовPage transitions

Brauzer qo'llasa, sahifalar View Transitions API bilan almashadi. CSS orqali sozlang yoki <main c-view c-transition="none"> bilan o'chiring. Uzoq yuklanishlarda yuqorida ingichka progress chizig'i paydo bo'ladi (--c-progress o'zgaruvchisi bilan rangini o'zgartiring).

Если браузер поддерживает, страницы меняются через View Transitions API. Настройте через CSS или отключите: <main c-view c-transition="none">. При долгой загрузке сверху появляется тонкая полоса прогресса (цвет — переменная --c-progress).

Where supported, pages swap using the View Transitions API. Customize with CSS or disable with <main c-view c-transition="none">. Slow loads show a thin progress bar (color it with --c-progress).
