Avto dark modeАвтоматическая тёмная темаAutomatic dark mode

Comet <html>'ga class="dark" va data-theme="dark|light" qo'yadi. Standart rejim — system (OS sozlamasiga ergashadi). Tanlov saqlanadi va sahifa chizilishidan oldin qo'llanadi — miltillash bo'lmaydi.

Comet ставит на <html> class="dark" и data-theme="dark|light". Режим по умолчанию — system (следует ОС). Выбор сохраняется и применяется до отрисовки — без мерцания.

Comet sets class="dark" and data-theme="dark|light" on <html>. The default mode is system (follows the OS). The choice is saved and applied before the first paint — no flash.

Варианты dark: в Tailwind сразу работают со стратегией class. :class не ломает существующие классы.

Tailwind's dark: variants work out of the box with the class strategy. :class never clobbers existing classes.
